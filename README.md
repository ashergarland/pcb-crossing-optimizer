# Crossing Analyzer

Bipartite graph crossing minimization for PCB connector pin assignment. Detects trace crossings in SKiDL-generated KiCad netlists and computes optimal pin orderings for single-layer routing.

## Usage

### Pair mode (two connectors)

```
python src/crossing_analyzer.py <netlist.net> <fixed_ref> <reorderable_ref> [--exclude REF:PIN ...] [--diagram]
```

Analyze the microSD breakout (excluding shield pin):
```
python src/crossing_analyzer.py examples/microsd_breakout.net J1 J2 --exclude J1:SH
```

With ASCII routing diagram and connection matrix:
```
python src/crossing_analyzer.py examples/microsd_breakout.net J1 J2 --exclude J1:SH --diagram
```

### Sweep mode (multi-layer, 3+ components)

```
python src/crossing_analyzer.py <netlist.net> --layers "L0_refs | L1_refs | L2_refs" --reorderable REF [REF ...] [--exclude REF:PIN ...]
```

Analyze the microSD breakout with passives in the middle layer:
```
python src/crossing_analyzer.py examples/microsd_breakout.net --layers "J1 | R1,R2,C1 | J2" --reorderable J2 --exclude J1:SH
```

Nets spanning non-adjacent layers (e.g., J1 to J2 through a passive layer)
are handled automatically via virtual pass-through nodes.

## How it works

1. Parses a KiCad .net file (S-expression format generated by SKiDL)
2. Extracts pin-to-net connectivity for specified connectors
3. **Pair mode**: counts crossings via O(n^2) inversion counting between two connectors
4. **Sweep mode**: Sugiyama-style barycenter sweep across multiple layers
   - Inserts virtual nodes for long edges spanning non-adjacent layers
   - Reorders both pins within reorderable components and components within layers
   - Iterates forward/backward sweeps until convergence
5. Computes optimal pin order using barycenter heuristic
6. Reports current crossings, recommended reordering, and remaining crossings
